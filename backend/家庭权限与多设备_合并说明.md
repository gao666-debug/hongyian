# 家庭权限与多设备接入草稿

基于 GitHub main 79b9411，保留已合并的手表逻辑。本草稿增加家庭管理员/照护者/只读成员；设备读写权限和 WebSocket 换票校验；NEARLINK_A_DEVICE_ID 独立配置；星闪属性上报按真实设备保存。

## 验证

后端原回归及家庭权限测试 34 项通过，另新增星闪 A 设备隔离与错误类型测试通过，共 35 项。没有部署服务器。

## 不可直接覆盖线上

队友交接称线上为 API 1.3.1，含视觉抓拍、AMQP 死信、多设备白名单和 shadow 服务匹配修复，这些改动并未全部同步到 GitHub main。本草稿不含这些生产改动，直接覆盖会丢失功能。

合并前需取得服务器当前源码，把本草稿以增量合并方式移植，再做回归：

- 保留线上 DEVICE_ID 多设备白名单约定；本草稿暂用主设备 + NEARLINK_A_DEVICE_ID + WATCH_DEVICE_ID，两个约定尚未统一。
- 保留线上 health 的星闪 light/smoke/body/door 扩展；本草稿仅实现星闪 device.property 分流，实际固件若只发 device_health，仍需对齐。
- 保留抓拍路由、图片鉴权、死信归档和生产服务启动方式。
- 当前为一个家庭共享设备的多账号，不是任意多家庭或多租户系统。成员由 owner 创建，无公共注册。
- 不支持的主板命令不能发给星闪节点；权限不能只靠 App 隐藏按钮。
- 备份原数据库，核对迁移、账户映射、会话与只读权限；补充服务器 received_at 后再统一时效判断。

公开模板不含 AK/SK、设备密钥、AMQP 凭据、实际登录密码、私钥或运行数据库。不要将 .env 和生产配置提交到仓库。
