# 颐鸿安：账号权限与报警协作（API 1.9.0 / App 1.14.0）

本次完成规划的第一、二阶段：独立账号权限、删除成员账号和报警协作。服务器目前的部署状态需由服务器维护者确认；本地代码与安装包完成不代表公网已经升级。

## 权限

| role | 名称 | 家庭数据与摄像头 | 设备控制 | 报警查看 | 认领与处置 | 账号管理 |
|---|---|---|---|---|---|---|
| owner | 家庭管理员 | 是 | 是 | 是 | 是 | 是 |
| caregiver | 家属／监护人 | 是 | 是 | 是 | 是 | 否 |
| viewer | 只读成员 | 是 | 否 | 是 | 否 | 否 |
| community | 社区网格员 | 否 | 否 | 是 | 是 | 否 |
| property | 物业值班人员 | 否 | 否 | 是 | 是 | 否 |

权限由服务器检查。网格员与物业在当前版本均可协作处理已授权家庭的全部报警，未按报警类型进一步划分。它们的 `/household` 不含传感器或手表数据，WebSocket 仅发送报警及协作事件。普通成员仅能看到自己的成员资料；管理员可看到本家庭成员列表。

App 的成员列表不再提供登录其他成员的捷径。本机保存的其他账号切换时必须输入该账号密码；保存新账号时清除其他账号的缓存令牌。只允许自动恢复本机上次使用的同一账号。

## 新接口

- `POST /api/v1/household/members`：原接口新增 `community`、`property` 角色。
- `PATCH /api/v1/household/members/{username}`：请求 `{"role":"community"}`，管理员修改权限，目标账号所有会话和未使用票据失效，需要重新登录。
- `DELETE /api/v1/household/members/{username}`：管理员删除账号、家庭关联、全部会话和票据；释放其认领，保留旧备注。禁止删除本人或管理员，禁止跨家庭操作。
- `POST /api/v1/devices/{device}/alarms/{event_key}/claim`：原子认领；同一人重试幂等，其他人认领返回 409。
- `DELETE /api/v1/devices/{device}/alarms/{event_key}/claim`：认领人释放，管理员可释放他人认领。

删除账号保留用户名墓碑，避免同名新账号与历史处理人混淆。原用户名不可再次注册。历史备注新增 `account_deleted` 标记，账号操作写入本地审计表。

## 处置闭环与实时同步

报警列表新增可选 `claim:{username,created}`。新 WebSocket 事件：

```json
{"type":"alarm_claim","device_id":"...","data":{"event_key":"boot:event","claim":{"username":"worker","created":1790000000}}}
```

释放时 `claim` 为 null。App 收到事件后刷新列表；收到 `alarm_note` 时也刷新已打开详情中的处置记录，不清空正在编辑的备注。

原备注接口增加可选 `client_request_id`；同用户、同事件、相同请求号重试不会重复落库，请求号配不同内容返回 409。未带此字段的旧客户端继续兼容。保存或批量处置遇到其他成员认领返回 409，管理员也需先明确释放认领。保存备注后释放认领；“需跟进”事件可再次认领。

认领可选，保留旧客户端直接保存备注的行为。确认事件、保存记录、设备 ack 与 mute 是不同操作，认领或保存记录不会自动控制设备，也不能代表现场异常已排除。

## 部署

1. 备份服务器现有代码与 SQLite 数据库，使用 SQLite backup 功能或停服务备份，避免遗漏 WAL。
2. 更新本包代码，保留服务器 `.env`、数据库和证书，继续使用当前监听地址、端口及 nginx 配置。
3. 使用已有虚拟环境安装/核对 `requirements.txt`；没有新增外部服务。
4. 重启 API 和 AMQP 两个既有服务。启动时自动创建 `alarm_claims`、`note_requests`、`account_audit`、`deleted_accounts` 表，无需删除或重建数据库。
5. `/healthz` 中 `api_version` 应为 `1.9.0`，再使用 App 1.14.0 验收。

请勿用交付包覆盖服务器环境变量，也勿在生产环境导入单测数据。App 可以继续连接旧后端查看旧有功能，但新角色、删除、修改权限和认领接口必须等 API 升级后才可用。
