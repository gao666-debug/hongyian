> **历史排查记录，以下推断已被修正。** ADO 实际在 WEAR J2-7，J2-6 是 AUX_CL；J2-4 是 Sensor_INT，不是 LCD RST。因此“IO6 拉低说明 CLK 在 IO8”不成立。固定接法为 CLK7/MOSI9/DC10/CS11/RST12；供电和通断须实测。请以 [圆屏固定引脚测试说明](圆屏固定引脚测试_给队友.md) 为准。

# 硬件与引脚

两块板：**WEAR**（手表扩展板，屏和传感器都焊在它上面）和 **EXB**（底板，WS63 核心板 + 各种座子）。
依据是两份原理图导出的网表：`HTXH_XS_WEAR_SCH`、`HTXH_XS_EXB_SCH`。

## 一、屏的 7 个脚（WEAR 板 `LCD1` 座）

座子型号 `KH-2.54FH-1X7P-H8.5`，屏模组是 1:1 直插，7 针全占满，没有可再引线的地方。

| LCD1 脚 | 网络 | 说明 |
| --- | --- | --- |
| 1 | VCC | 接挂板电源，模组背面自带 LDO（U3）+ C3~C7 |
| 2 | GND | |
| 3 | `SPI0CK` | 时钟 |
| 4 | `SPI0MOSI` | 数据 |
| 5 | `DC` | 命令/数据 |
| 6 | `SPI0CS` | 片选 |
| 7 | `RST` | 复位 |

模组背面丝印是 `RST CS DC DA CL GD VC`，与座子顺序逐位一致，**不存在插反或镜像**。
（插反的话 VCC 会落到某个 IO 上，弱上拉必然拉不起来，实测不存在这种情况。）

## 二、WEAR 板的两排针

网表里两根线各只挂一个连接器脚，很干净：

```
NLSPI0CK   = { PIJ208, PILCD103 }        J2-8  → LCD1-3
NLSPI0MOSI = { PIJ109, PILCD104 }        J1-9  → LCD1-4
NLDC       = { PIJ108, PILCD105 }        J1-8  → LCD1-5
NLSPI0CS   = { PIJ107, PILCD106 }        J1-7  → LCD1-6
NLRST      = { PIJ204, PIJ106, PILCD107 }J2-4 / J1-6 → LCD1-7
```

结论：**5 根信号里 4 根走 J1（12 针），只有时钟走 J2（10 针）**。

## 三、EXB 板的四排针

EXB 上 J1 与 J2 是同一组网络（并排引出），J3 与 J4 同理。从网表逐行读出来：

| 脚 | J1 / J2 | 脚 | J3 / J4 |
| --- | --- | --- | --- |
| 1 | （电源/地，见原理图） | 1 | **I2C SCL** |
| 2 | IO0 | 2 | **I2C SDA** |
| 3 | IO1 / UART0_RXD | 3 | IO14 |
| 4 | （空） | 4 | IO3 |
| 5 | IO2 / UART0_TXD | 5 | IO13 |
| 6 | IO4 | 6 | **IO12 = RST** |
| 7 | IO5 | 7 | **IO11 = CS** |
| 8 | **IO6** | 8 | **IO10 = DC** |
| 9 | IO7（另引到 J7-1） | 9 | **IO9 = MOSI**（另引到 J8-1） |
| 10 | IO8 | 10 | GND |
| 11 | | 11 | 3V3 |
| 12 | | 12 | 5V0 |

另有三个单针测试点：`J6-1 = IO3`、`J7-1 = IO7`、`J8-1 = IO9`。

## 四、两板怎么对接

WEAR 的 **J1（12 针）** 插进 EXB 的 **J3/J4**，一一对应（I2C 能通就是这个前提的直接证据）：

| WEAR J1 | EXB J3 | 结果 |
| --- | --- | --- |
| 1 / 2 | SCL / SDA | ✅ I2C 通，MAX3010x 读得到 |
| 6 | IO12 | ✅ RST |
| 7 | IO11 | ✅ CS |
| 8 | IO10 | ✅ DC |
| 9 | IO9 | ✅ MOSI |

WEAR 的 **J2（10 针）** 插进 EXB 的 **J1/J2**（12 针），**对齐位置决定了时钟落在哪个脚**：

| J2 与 EXB 的对齐 | J2-8（时钟）落在 | J2-6（ADO）落在 |
| --- | --- | --- |
| 第 1 针对第 1 针 | EXB-8 = **IO6** | EXB-6 = IO4 |
| 往内错 1 针 | EXB-9 = **IO7** | EXB-7 = IO5 |
| 往内错 2 针 | EXB-10 = **IO8** | EXB-8 = **IO6** |

## 五、时钟到底在哪个脚（未决）

三条互相独立的线索指向同一个矛盾：

1. **芯片侧**：官方 `200_lcd_display` 与《星闪套件实验指导手册》都用 `SPI_CK = IO7`。
2. **底板侧**：`IO7` 只引到 `J7-1`（3 针按键排针）和 J1/J2 的第 9 脚，
   没有别的支路——如果 WEAR 的 J2 没插，时钟就是断的。
3. **实测侧**：`IO6` 被外部死死拉低（内部上拉读到 0、下拉也读到 0）。
   能把它拉这么死的，最可能就是 MAX3010x 的 `ADO`（模块上直接接地，用来定 I2C 地址）。

把第 3 条和第 4 节的表对一下：**只有「往内错 2 针」这一种对齐能让 ADO 落在 IO6**，
而它同时意味着 **时钟落在 IO8**。另外两种对齐会把 ADO 压到 IO4/IO5（都在 QSPI0
主 Flash 总线范围内），那样固件根本起不来——但板子每次都正常启动，所以可以排除。

**当前假设：SPI_CK 实际在 IO8，而代码里写的是 IO7。**

这条还没被证实，因为 RDDID 读回在 8 个候选脚上全是 FF（可能是模组 SDA 不可回读导致的
假阴性）。固件里的「肉眼终审」（9 种组合各刷一次红屏）就是为了绕开读回、直接看结果。
实测数据见 [`点亮排查记录.md`](点亮排查记录.md)。

## 六、供电

- LCD1-1 在 WEAR 板上接的是挂板 VCC；EXB 的 J3-11 是 3V3、J3-12 是 5V0。
- 模组背面有 U3（三脚 LDO）+ C3~C7，5 V 进、3.3 V 出，**供电不是问题**。
- 背光 LED 不经过屏的控制器，所以「背光亮」只能证明 VCC/GND 两个焊点是好的，
  **不能**证明另外 5 根信号线通。
