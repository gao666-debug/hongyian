# 点亮排查记录

目标：让 WEAR 板 `LCD1` 座上的 1.28″ GC9A01 圆屏显示出画面。
现状：**背光常亮、画面均匀灰、控制器不应答**。下面是每一轮做了什么、量到什么、
排除了什么。固件版本号即 `tools/flash.py` 烧进去的 `.fwpkg` 序号。

## 已经排除的假设

| 假设 | 怎么排除的 |
| --- | --- |
| 驱动代码写错 | 与官方 `200_lcd_display` 逐行对比，除多加延时外完全一致 |
| 引脚定义错（角色互换） | 12 种排列（时钟/数据互换 × DC/CS/RST 六种轮转）全扫，屏一次没回 |
| 屏插反 180° | 插反时 VCC 会落到某个 IO 上，弱上拉必然拉不起来；实测 5 个信号脚用内部 50 kΩ 上拉都能读到 1 |
| 屏针脚悬空、要飞线 | 7 针 1:1 直插 `LCD1` 座，物理上没有第二处可接 |
| 5 V 供电打坏控制器 | 模组背面有 U3（三脚 LDO）+ C3~C7，5 V→3.3 V，供电正常 |
| 别的外设占了引脚 | 工程内 I2C 在 IO15/IO16，雷达和蓝牙都不碰 IO6~IO14 |
| 引脚驱动能力不足 | 5 根脚逐个测「推高读回 + 推低读回」，全部 `drv=10` |
| 线材断/虚焊（RC 时间法） | 该方法本身无效：内部下拉几十 kΩ，对 pF 级电容根本量不出时间差。此结论已作废 |
| 屏模组坏 | 换过一块屏，现象完全一样；座上 7 针共用，换屏不改变任何电气条件 |

## 关键实测数据（v25 / v27）

三态回读，`up` = 内部上拉时的读数，`dn` = 内部下拉时的读数，`drv` = 推高/推低能否读回：

```
IO7  CLK   up=1 dn=0 drv=10  高阻（正常）
IO9  MOSI  up=1 dn=0 drv=10  高阻（正常）
IO10 DC    up=1 dn=0 drv=10  高阻（正常）
IO11 CS    up=1 dn=0 drv=10  高阻（正常）
IO12 RST   up=1 dn=1 drv=10  外部有上拉（屏 RST 上拉，符合预期）
IO6        up=0 dn=0         被外部拉死
IO13       up=0 dn=0         被外部拉死
IO14       up=0 dn=0         被外部拉死
```

`IO6` 被拉死这条最有价值：能把它拉到 0 的，最可能是 MAX3010x 的 `ADO`（模块上接地定地址）。
把这条和 `硬件与引脚.md` 第 4 节的对接表对起来，**只有「J2 往内错 2 针」这一种对齐能让
ADO 落在 IO6**，而它同时意味着**时钟落在 IO8**。

`IO13`/`IO14` 被拉低，对应 WEAR 的 `J1-3`/`J1-5`（传感器中断类信号），不影响屏。

## v27 加的三件事

1. **短路图**：9 个候选脚两两配对，先把被测端预充 0，再驱动另一端为 1，读被测端。
   纯高阻输入会保持原电平，所以只有真的直连才会变 1。
   用途：如果两根信号线在板上被短接，SPI 永远不可能通，先把这个排除掉。
2. **修掉假阳性**：只有「内部上拉能读到 1」的脚才允许当 SDA。被拉死的脚永远读 0，
   拿它当 SDA 会造出「全 00」的假应答。
3. **肉眼终审**：RDDID 依赖屏把 SDA 反向驱动，串了 1 kΩ 或单向电平转换的模组会永远读 FF。
   所以最后不读、只写：9 种引脚组合各做一次完整初始化 + 整屏填红，每组停 2 秒。
   9 组分别是
   `(7,9,10,11,12)`、`(8,9,10,11,12)`、`(6,9,10,11,12)`、`(8,7,10,11,12)`、
   `(7,8,10,11,12)`、`(6,8,10,11,12)`、`(9,8,10,11,12)`、`(8,9,11,10,12)`、`(8,9,10,12,11)`，
   顺序是 `(clk, mosi, dc, cs, rst)`。
   前三个是重点：`IO7` = 代码现状、`IO8` / `IO6` = 由对接错位推出来的两种可能。

## 如果 v27 的 9 组里出现红色

记下编号，把 `lcd_init.h` 里的 `LCD_SCL_PIN` / `LCD_SDA_PIN` / `LCD_DC_PIN` /
`LCD_CS_PIN` / `LCD_RST_PIN` 改成那一组，关掉 `board_check`，重新编译即可。

## 如果 9 组全都不红

那就只剩物理层，按代价从低到高：

1. **量通断**：万用表蜂鸣档，`LCD1` 第 3 针 ↔ `IO7` 测试点、第 4 针 ↔ `IO9`、第 5 ↔ `IO10`、
   第 6 ↔ `IO11`、第 7 ↔ `IO12`。不通的那根就是断点。
2. **看焊点**：`LCD1` 座背面 7 个焊盘的微距照，重点看 3~7 针有没有虚焊/漏焊。
   注意：背光只走第 1、2 针，所以「背光亮」完全不能证明 3~7 针焊好了。
3. **换板**：以上都排除就是屏模组或座子的批次问题，找供应商换。
