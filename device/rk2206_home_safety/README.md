# 通晓主板业务源码 v3.5.44

本目录为 TX-SMART-R / RK2206 的业务应用，不是完整 SDK。集成到匹配的 OpenHarmony 通晓 SDK 的 vendor/isoftstone/rk2206/samples/d3_home_safety，并使用该 SDK 已有的硬件适配层、构建配置与工具链；不保证可直接复制到未经适配的其他 SDK 编译。BUILD.gn 列出依赖。

复制 include/*.example.h 为对应的 *_private.h，填写本地云端和 Wi-Fi 参数。原始密钥、设备鉴权密码和 Wi-Fi 密码不提交。tools 下提供配置辅助脚本。主板当前明确使用 1883 明文演示连接，未完成实板 TLS 验证；不要理解为已经支持安全生产部署。

本次语音协议：01 01 开灯、01 02 关灯、00 01 自动、00 02 关闭自动；03 01/03 02 查询温湿度；扩展指令 10~15 前缀见 `include/su_03t.h`。控制 RGB 夜灯，报警和服药指示优先；重启或保存生活设置后恢复配置。语音模块必须输出匹配协议。

**语音词条要单独配、单独烧。** 模块出厂只有 1~3 号数值词条，报警 4~9 与应答 10~22 需要按 `docs/su03t_词条表.csv` 在 SU-03T 平台配好并烧录，再把 `VOICE_DEDICATED_IDX` 置 1。完整步骤、词条文本、验证与排错见仓库 `docs/语音词条配置与烧录说明.md`。烧录后可用 `-DSU03T_SELF_TEST=1` 上电逐条试听 4~22 号，验证完改回 0。

本地 GCC/UBSan 回归和完整 SDK 编译通过；未进行本次实板语音验收。没有提供烧录镜像，也没有包含完整 SDK 的历史适配改动。
