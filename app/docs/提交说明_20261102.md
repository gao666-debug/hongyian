## 公开副本配置

仓库使用 demo-device、backend.example.com 及示例局域网地址；摄像头密码留空。实际端点、设备 ID、摄像头账号密码请在自己的环境配置，不提交账号密钥、签名文件、数据库、.env 或编译产物。证书资源是公开证书，不含私钥。

当前登录设备 ID 自动发现尚待实现：Backend.device 与 Index 中 DEVICE 必须配置同一主板 ID。登录仅保存 access_token，还未完整消费线上 device_ids。摄像头进入后自动尝试已保存地址，再搜索局域网；首次需在连接设置填入自己的密码。模拟器的虚拟网段与电脑网段不同时可填写实际摄像头地址。
