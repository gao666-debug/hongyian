# 颐鸿安 1.7.0 · 星闪环境与随身健康

## 入口

- 设备 → 房间环境：查看环境节点。
- 设备 → 随身健康，或总览 → 随身健康：查看手表数据。
- 主板总览和摄像头页面保持原入口。

## 环境节点

读取授权环境节点的 `/shadow`、`/health`，显示光照/烟雾 ADC 原始电压（mV）、人体活动、房门及上报时间。属性影子缺失时允许使用健康快照。只有真实上报了温湿度才显示，空值不当作 0。多节点可切换，每台独立读取。

PIR 不是距离传感器，未检测到活动不等于房间无人。ADC 电压不是 lux 或 ppm，不据此推断安全状态。

## 手表

沿用队友 API 1.4.0 与整合版 1.4.1 的主设备聚合接口：

- `/api/v1/devices/{主设备}/watch`：心率、血氧、累计步数、活动强度与跌倒判定。
- `/watch/hours?limit=12`：有效心率小时均值与步数增量，UTC 小时桶转为本机时间显示。
- `/watch/falls?limit=20`：跌倒原始判定历史。

心率/血氧为 0 时显示“待测量”。手表步数不是承诺的每日步数。过期数据明确提示。手表原始跌倒记录尚不能通过主板 ack 清除，也尚未接通统一 alarm_event 与自动抓拍，不显示虚假的处理按钮。

## 登录与刷新

登录使用服务器返回的 `device_ids`；家庭接口可用时使用其设备类型，旧版无家庭接口时按授权清单读取扩展节点。令牌仅在内存共享，不写路由参数。页面前台每 6 秒查询，无重叠请求，切页及选设备后丢弃旧响应。

星闪板不在线时，只能显示后端保留的历史或“待上报”，不会补假数据。新页面需先登录真实后端；不依赖模拟数据启动。
