## 快速判断"数据为什么没上来"

按这个顺序查（三块硬件通用）：

1. **设备在不在线** —— IoTDA 控制台设备状态是否 `ONLINE`
2. **云平台收没收到** —— IoTDA「消息跟踪」，看 `properties/report` 或 `messages/up` 是否出现
3. **转发规则有没有把它放行** —— 控制台「规则 → 数据转发」，`where` 条件里的 device_id 是否覆盖这台设备
4. **后端入库没有** —— 服务器上 `sqlite3 backend.sqlite3 "select device,count(*) from inbox group by device;"`
5. **AMQP 消费者是否活着** —— `journalctl --user -u eldercare-amqp`，要看到 `Device message persisted`

> 第 5 步特别容易误判：服务 `systemctl is-active` 显示 `active` 也可能是重连死循环，
> 要看日志有没有 `AMQP connected`。
