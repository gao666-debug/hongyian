## 一、E53 接口提供的信号（原理图确认）

通晓板有一个 **E53 标准接口**（18-pin 引出接口），实际引出的网络标号如下：

| 类别 | 信号名 | 对应引脚 |
|---|---|---|
| **电源** | `VCC_5V` | 5V |
| | **`VCC_3V3`** | **3.3V** ← 接门磁用这个 |
| | `GND` | 地 |
| **纯 GPIO** | **`E53_GPIO_A2`** | GPIO0_PA2 |
| | `E53_GPIO_A5` | GPIO0_PA5 |
| PWM（可当 GPIO） | `E53_PWM0_M1_GPIO_B4` | GPIO0_PB4 |
| | `E53_PWM1_M1_GPIO_B5` | GPIO0_PB5 |
| | `E53_PWM7_M1_GPIO_D0` | GPIO1_PD0 |
| I2C | `E53_I2C0_SCL_M2` / `E53_I2C0_SDA_M2` | I2C0 |
| SPI | `E53_SPI1_CLK_M1` / `E53_SPI1_CS_M1` | SPI1 |
| UART | `E53_UART2_TX_M1` / `E53_UART2_RX_M1` | UART2 |
| ADC | `E53_ADC` | 1 路模拟输入 |

## 二、⚠️ 板载外设已占用的引脚（别撞车）

我从源码里逐个查了板载外设用的引脚：

| 引脚 | 被谁占用 | 出处 |
|---|---|---|
| GPIO0_PA0 / PA1 | **I2C0**（SHT30 温湿度 + BH1750 光照） | `hdf_drivers/i2c/i2c_driver_rk2206.c` |
| GPIO0_PA3 | **人体红外传感器** | `b2_gpio_interrupt` |
| GPIO0_PA4 | **LCD 的 DC 线** | `c2_lcd/src/lcd.c` |
| GPIO0_PA5 | **报警灯 / LED** | `b1_gpio/gpio_example.c` |
| GPIO0_PB4 / PB5 / GPIO1_PD0 | **RGB 三色灯** | `d1_smart_home/src/smart_home.c` |
| GPIO0_PC0~PC3 | **LCD SPI**（CS/CLK/MOSI/RES） | `c2_lcd/src/lcd.c` |
| GPIO0_PC0 / PC5 | **ADC**（可燃气体等） | `hdf_config/adc_config.hcs` |
| GPIO0_PC7 | **按键** | `b2_key_scan`、`b16_wifi_pair` |
| GPIO0_B2 / B3 | **语音模块串口**（UART2） | `e1_iot_smart_home` README |

**结论：`GPIO0_PA2` 是唯一完全空闲的引脚，而且正好引出在 E53 上。**

> 注：`E53_GPIO_A5` 虽然引出，但 PA5 同时是板载报警灯，**可能并联**；
> `E53_PWM0/1/7` 对应的 B4/B5/D0 同时是 RGB 灯。这几个都有冲突风险，**别用**。

## 三、推荐接法（3 根线）

| KY-025 引脚 | 接到 E53 的 | 说明 |
|---|---|---|
| **VCC** | **`VCC_3V3`** | ⚠️ **绝对不要接 `VCC_5V`** |
| **GND** | `GND` | |
| **DO** | `E53_GPIO_A2` | 即 GPIO0_PA2 |
| AO | 不接 | 模拟输出，用不上 |

### ⚠️⚠️ 为什么绝不能接 5V

KY-025 板上的 DO 是 **LM393 比较器的开集输出**，上拉电阻接到模块的 VCC。
**如果 VCC 给了 5V，DO 输出的高电平就是 5V**，而 RK2206 的 IO 是 **3.3V** —— 5V 打进 IO 口会**击穿芯片**。

E53 接口上 **5V 和 3.3V 两路电源都有**，这是最容易插错的地方。
**接线前一定对着原理图数清楚孔位再插。**

## 四、代码怎么写

直接照抄通晓现成案例 `vendor/isoftstone/rk2206/samples/b2_gpio_interrupt/`（GPIO 中断），
把原来的人体红外引脚改掉即可：

```c
// 原来是： #define GPIO_BODY_INDUCTION  GPIO0_PA3
#define GPIO_DOOR_MAGNET     GPIO0_PA2   // 门磁 DO 接 E53_GPIO_A2
```

逻辑：磁铁靠近 → DO 电平变化 → 判定「门关」；磁铁离开 → 判定「门开」。

### ⚠️ 先实测电平逻辑再写死

不同批次模块的极性可能相反（有的磁铁靠近输出低电平，有的输出高电平）。
**建议第一步只写个串口打印**，手拿磁铁靠近/离开看电平怎么变，确认后再写判断逻辑。

## 五、还需要买的东西

**磁铁**。KY-025 模块通常**不含磁铁**，需要单独买一块钕磁铁才能触发。下单前确认商品是否含磁铁。
