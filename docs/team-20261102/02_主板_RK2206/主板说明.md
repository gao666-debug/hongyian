## 二、编译方法（需要源码，本机没有）

官方推荐「**Docker 编译 + Windows 烧录**」：

```bash
# 1. 在 OpenHarmony 源码根目录（含 build.py 的那层）
hb set -root .
# 选择 txsmart_rk2206 产品

# 2. 编译
hb build -f

# 3. 产物
out/rk2206/txsmart_rk2206/libs/... → 汇总成两个文件：
#   rk2206_db_loader.bin   引导
#   Firmware.img           固件
```

详细环境搭建（Docker 镜像、依赖、踩坑）见
`../../06_鸿蒙赛题_环境搭建/01_通晓开发板_环境搭建实操方案.md`（不在本包内，如需可单独要）。

## 三、烧录方法（Windows 原生，必须）

> ⚠️ 烧录只能在 Windows 上做，Linux/Docker 里不行。

1. 装驱动：`DriverAssitant`（瑞芯微 USB 驱动）
2. 用 USB 线连板子的 **OTG/烧录口**（不是串口）
3. 打开 `RKDevTool.exe`
4. 分别加载：
   - `rk2206_db_loader.bin`
   - `Firmware.img`
5. **进入 MASKROM 模式**：按住板上的 `MASKROM` 键 → 按一下 `RESET` 键 → 全部松开
6. RKDevTool 提示「发现一个 MASKROM 设备」→ 点「执行」
7. 等待完成，板子自动重启

> ⚠️ 安全提醒：烧录前建议用 USB 隔离器。错误的电气连接可能损坏 SoC 或 USB 接口电路。

## 四、接线

| 外设 | 接口 | 引脚 | 详细文档 |
|---|---|---|---|
| 门磁（KY-025） | E53 接口 | `VCC_3V3`、`GND`、`E53_GPIO_A2`（GPIO0_PA2） | `门磁接线说明_E53接口.md` |
| 无线求助按钮 | E53 接口 | 原定 `GPIO0_PB5` | `无线求助按钮_选型与接线规格.md` |

> ⚠️ **求助按钮的引脚有冲突**：`GPIO0_PB5` 在通晓官方三个案例里都被定义为板载 RGB 红灯
> （`drv_light.c` 中 `#define LED_R_GPIO_HANDLE GPIO0_PB5`），很可能不是空闲脚。
> 接线前务必看 `无线求助按钮_选型与接线规格.md` 里的一节，或与队友确认改脚。

## 五、这块板支持命令下发

是**三块板里唯一支持**的：

| 命令 | 作用 |
|---|---|
| `ack` | 消警（报警后确认） |
| `mute` | 静音 |
| `set_living` | 设置夜间灯等生活参数 |
| `confirm_medicine` | 确认某次服药 |
| `set_medicine_plan` | 设置三个服药时段 |
| `set_medicine_state` | 单次确认 / 撤销 |

调用方式与参数见 `01_总览/系统总览与设备清单.md` 第四节。
