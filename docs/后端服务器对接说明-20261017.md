### 3.4 命令接口的字段（易错）

```json
POST /api/v1/commands
{
  "device_id": "6acdec5b18855b39c5552ec3_TXSMART001",
  "command_name": "ack",        // 枚举 ack | mute（字段名不是 command）
  "paras": {},                  // 可选
  "client_request_id": "唯一ID"  // 必填，服务端用于去重
}
```

- 返回 `accepted` + `state=pending` —— **仅表示后端已接受，不等于设备已执行**
- 必须再查 `GET /api/v1/commands/{command_id}`，直到终态：

| state | 含义 |
|---|---|
| `pending` | 待完成 |
| `executed` | 设备已执行（`result_code=0`） |
| `failed` | 明确失败 |
| `unknown` | 结果未知（云端超时；**不等于执行成功，也不代表未执行**） |

### 3.5 WebSocket（易错）

```
wss://47.116.171.114:8443/api/v1/ws?ticket=<ticket>&device_id=<device_id>
                                          ↑ 两个参数都必须带，缺 device_id 直接 403
```

流程：
1. `POST /api/v1/ws-ticket?device_id=<id>` 申请 ticket（**有效期仅 30 秒**）
2. 用上述 URL 连接（WSS，证书为自签，需 App 侧信任）
3. 首条推送：`{"schema":1,"type":"hello","device_id":...,"timestamp":...,"mode":"live","simulated":false}`
4. 心跳：每 15 秒 `{"type":"ping"}`
5. 事件类型：`alarm` / `health` / `stats` / `command_ack`
6. 客户端可发任意短文本保活（≤1024 字节，**服务端不执行命令**）

消息外层结构：`{schema, type, device_id, timestamp, data}`

### 3.6 云端回调（IoTDA → 服务器）

- 路径：`POST /api/v1/iotda/notifications`
- 鉴权：**`X-Webhook-Token: <WEBHOOK_TOKEN>`** 请求头，或查询参数 `?token=<WEBHOOK_TOKEN>`
- 资源 `device.message`、事件 `report`
- 接收原始消息类型：`alarm_event`、`device_health`、`activity_stats`

## 五、运维信息（供排查）

### 5.1 服务管理

> ⚠️ `deploy` 的 uid 是 **1001**，且必须设 `XDG_RUNTIME_DIR`，否则 `systemctl --user` 直接报错。
> ⚠️ `/home/deploy` 权限是 `drwxr-x---`，**其他账号进不去**，必须用 `sudo -u deploy`。

```bash
SYS='sudo -u deploy env XDG_RUNTIME_DIR=/run/user/1001 systemctl --user'
JRN='sudo -u deploy env XDG_RUNTIME_DIR=/run/user/1001 journalctl --user'

$SYS status eldercare-api.service
$SYS restart eldercare-api.service
$SYS restart eldercare-amqp.service
$JRN -u eldercare-api.service -n 50 --no-pager
$JRN -u eldercare-amqp.service -n 50 --no-pager
```

### 5.2 关键路径

| 路径 | 说明 |
|---|---|
| `/home/deploy/app` | 代码 |
| `/home/deploy/app/.env` | 配置（**权限 600**，含云端密钥） |
| `/home/deploy/app/.local/backend.sqlite3` | 数据库（**勿删**，存历史报警与统计） |
| `/etc/nginx/sites-available/qbot-api` | nginx 配置（8443 → 8000） |
| `/etc/nginx/ssl/self.crt` | **公开证书**（App 信任配置用这个，私钥不外发） |

### 5.3 注意事项

1. **单 worker 不能改** —— WebSocket 状态保存在进程内，多 worker 会导致推送错乱
2. **AMQP 队列同时只能有一个消费者** —— 服务器已启用，**本机不要再开** `consume_cloud.py`
3. **改 nginx 配置后要 `systemctl restart nginx`** —— 实测 `reload` 在本机不生效
4. **`.env` 权限保持 600**，不要提交到代码库
5. **更新代码时不要删数据库**
6. **`/docs`、`/openapi.json` 已对外封闭** —— 需要看接口文档时走 SSH 隧道访问 `127.0.0.1:8000/docs`
