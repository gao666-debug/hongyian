## 8 · ⚠️ 三个"版本不同源"的坑（别答错）

1. **仓库里的 App 是 1.16.6，不是当前版本。** 最新 1.16.11 在 `F:/hongyian-app-build`。讲 App 就打开 build 目录，别说"仓库里这份就是现在的"。
2. **板子固件只到 v3.5.58 有源码。** 本地刷的是 v3.5.58；v3.5.59/60/61（按键标定）只有 `Firmware.img` + `源码变更.tar.gz` 里的两个文件（`key.c`、`su_03t.c`）。
3. **摄像头固件只到 v0.3.4 有 .ino 备份。** v0.3.5 只有合并后的 bin（`固件/ESP32-CAM_v0.3.5/`），源码改动是 `HomeSafetyCamera.ino.bak_v032` 之后的合并版本，讲的时候说"v0.3.5"即可，别现场找 diff。

## 9 · 一句话技术栈总结（被问"用了什么"时）

- **端侧**：OpenHarmony / ArkTS（App）、LiteOS + C（RK2206 主板）、WS63 SDK + 星闪 SLE（手表/环境节点）、ESP32 + Arduino（摄像头）
- **云侧**：华为云 IoTDA（MQTT 接入）、AMQP 订阅、FastAPI + SQLite、WebSocket 推送
- **近场**：NFC 被动标签（NT3H）写 NDEF URI，碰一下打开板子本地网页；Wi-Fi 局域网直连，不依赖公网
- **协议**：REST + WS（App↔后端）、MQTT/TLS（设备↔IoTDA）、HTTP 8080（本地网页）、HTTP 80/81（摄像头取图/串流）
