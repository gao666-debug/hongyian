## 4. 速查

### 网络模式（AP / STA 二选一）
- **AP 模式**：开热点 `HomeSafety`/`12345678` + HTTP `http://192.168.2.1:8080`（App 直连）；不上云。
- **STA 模式**：连路由器/热点（出厂 SSID/密码见固件 `safety_runtime.c` 的出厂配置，不在文档中明文写出）上云 MQTT；HTTP 走板子 STA IP。
- 开机**自动选**（先试 STA 成功用 STA，否则 AP）；**长按 K5** 切换并重启（偏好存 Flash）。

### 按键
| 键 | 短按 | 长按(~2s) |
|---|---|---|
| K3 | 求助 锁定/解除 | — |
| K4 | 消音 | — |
| K5 | 翻页 | **切 AP/STA 并重启** |
| K6 | 主界面取消报警 / 事件页清记录 | — |

### HTTP 接口（AP 模式下 `http://192.168.2.1:8080`）
`/status`、`/events`、`/info`、`/stats`、`/ack`、`/mute`（详细字段见北向接口说明）。
