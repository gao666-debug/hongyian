# 语音词条配置与烧录说明（SU-03T）

主板 `device/rk2206_home_safety` 的语音功能由板载 **SU-03T** 模块承担。代码里已经把词条编号、串口协议、播报策略全部写好，但 **SU-03T 出厂只有 1~3 号数值词条和几条查询词**，4~22 号词条必须先在模块里配出来并烧录，主板发过去的帧才有声音。

这份文档就是补上「配词条 + 烧录 + 验证」这一段。之前只在 `include/su_03t.h` 的注释里列了编号，模块侧没有实际配置，凡是没配的编号，主板发出后模块会直接忽略（无声，不报错）。

---

## 1. 硬件与串口

| 项目 | 取值 |
| --- | --- |
| 模块 | SU-03T（板载，离线识别 + TTS） |
| 连接 | 主板 UART2：`GPIO0_B2`(TX) / `GPIO0_B3`(RX) |
| 波特率 | **115200**，8 数据位，无校验，1 停止位，无流控 |
| 代码位置 | `src/su_03t.c`，`su03t_init()` 里配置 |

模块供电与麦克风/喇叭按模块手册接线；烧录时用 USB-TTL 接模块的下载口，烧完再插回主板。

---

## 2. 帧格式（主板 ↔ 模块）

**模块 → 主板（识别结果，两字节）**

```
<前缀> <参数>
例：0x13 0x01   → 开灯
    0x10 0x01   → 紧急呼救
```

**主板 → 模块（播报固定句，六字节）**

```
AA 55 <词条号> 00 55 AA
例：AA 55 0D 00 55 AA → 播第 13 号「已发出紧急求助」
```

**主板 → 模块（播报数值，十三字节）**

```
AA 55 <数值词条号> <8 字节 double，小端> 55 AA
例：AA 55 01 <temp 的 double> 55 AA → 播温度
```

> 数值帧要求模块侧把该词条配成「变量播报」，变量类型选 **8 字节 double / 小端**，否则会播成乱码或 0。

## 3. 播报词条表（主板 → 模块）

编号与 `include/su_03t.h` 中的 `SU03T_SAY_*` 一一对应，**不要改号**，改号必须同步改代码。

### 3.1 报警词条 4~9（`VOICE_DEDICATED_IDX=1` 时启用）

| 号 | 用途 | 建议播报文本 | 触发条件 |
| --- | --- | --- | --- |
| 4 | 长时间无活动 | 检测到长时间没有活动，请确认一下情况 | 无活动超时报警 |
| 5 | 环境异常 | 房间温湿度异常，请检查 | 温度/湿度越限 |
| 6 | 燃气泄漏 | 检测到燃气浓度偏高，请立即开窗通风 | 燃气超 `GAS_PPM_LIMIT` |
| 7 | 疑似跌倒 | 检测到可能跌倒，请确认是否需要帮助 | 跌倒判定（原型保留） |
| 8 | 紧急求助 | 已发出紧急求助，请等待家人回应 | 按键/语音/App 呼救 |
| 9 | 服药提醒 | 到服药时间了，请按时服药 | 服药时段到期，需 `SU03T_MEDICINE_PROFILE_ENABLED=1` |

### 3.2 操作应答词条 10~22（`SU03T_ACTION_VOICE_ENABLED` 时启用）

| 号 | 用途 | 建议播报文本 |

| 11 | 关灯成功 | 已关灯 |

| 14 | 解除求助 | 已解除求助 |
| 15 | 静音 | 已静音报警 |
| 16 | 取消静音 | 已恢复播报 |
| 17 | 服药已确认 | 服药已确认 |
| 18 | 无待服药 | 现在没有需要确认的服药 |
| 19 | 数据不可用 | 数据暂时不可用，请稍后再试 |
| 20 | 燃气偏高 | 燃气浓度偏高，请开窗通风 |
| 21 | 燃气正常 | 燃气未检出异常 |
| 22 | 设备忙 | 设备正忙，请稍后再试 |

### 3.3 数值词条 1~3（出厂已有，确认存在即可）

| 号 | 用途 | 类型 |
| --- | --- | --- |
| 1 | 温度 | 变量播报（double 小端） |
| 2 | 湿度 | 变量播报（double 小端） |
| 3 | **光照**（不是燃气） | 变量播报（double 小端） |

## 4. 识别词条表（模块 → 主板）

每条识别词在平台里配「串口输出」为下表的两字节，主板对参数做范围校验，非法参数直接丢弃。

| 前缀 | 参数 | 建议口令 | 效果 |
| --- | --- | --- | --- |
| `0x10` | `0x01` | 小颐救命 | 发起紧急求助（等同按键呼救） |
| `0x10` | `0x02` | 小颐没事了 | 解除求助 / 确认报警 |
| `0x11` | `0x01` | 小颐静音 | 静音蜂鸣与播报 |
| `0x11` | `0x02` | 小颐恢复播报 | 取消静音 |
| `0x12` | `0x01/02/03` | 小颐我吃过药了（第 1/2/3 时段） | 确认对应时段服药 |
| `0x12` | `0x04` | 小颐确认服药 | 确认当前待服药时段 |
| `0x13` | `0x01` | 小颐开灯 | 夜灯常亮（临时覆盖） |
| `0x13` | `0x02` | 小颐关灯 | 夜灯关闭 |
| `0x13` | `0x03` | 小颐自动灯光 | 恢复自动夜灯 |
| `0x14` | `0x01` | 现在温度多少 | 播报温度 |
| `0x14` | `0x02` | 现在湿度多少 | 播报湿度 |
| `0x14` | `0x03` | 燃气浓度多少 | 播报燃气是否超标 |
| `0x14` | `0x04` | 光照多少 | 播报光照值 |
| `0x14` | `0x05` | 温湿度多少 | 先温度、1.4 秒后湿度 |
| `0x15` | `0x01` | 看第一页记录 | LCD 记录第一页 |
| `0x15` | `0x02` | 看第二页记录 | LCD 记录第二页 |
| `0x15` | `0x03` | 返回主页 | LCD 回主页 |

出厂遗留前缀仍然兼容，不必删：`0x01 01/02` 开关灯、`0x00 01/02` 自动/关灯、`0x03 01/02` 温度/湿度（`0x03 03` 出厂是光照，主板不响应）。

## 5. 配置与烧录步骤

0. **先跑一致性检查**（30 秒，能挡掉最常见的一类返工）：

   ```bash
   cd device/rk2206_home_safety
   python tools/check_voice_table.py           # 词条号、十六进制、指令前缀逐条比对
   python tools/check_voice_table.py --frames  # 顺带打印每条播报该发的串口帧
   ```

   它会把 `su_03t.h` 里的 `SU03T_SAY_*` / `SU03T_PFX_*` 与词条表逐条对齐，
   输出「头文件有、词条表缺」「参数超范围」「前缀固件不处理」这类问题。
   退出码非 0 就说明表有问题，改完再配模块，比烧完才发现播错强。

1. **建产品**：打开 SU-03T 的配置平台，新建一个产品，模块型号选 SU-03T，语言选普通话。
2. **加识别词条**：按第 4 节逐条添加「命令词」，每条在「控制 → 串口输出」里填两字节十六进制（如 `13 01`）。唤醒词用「小颐」。
3. **加播报词条**：按第 3 节添加 4~22 号「回复语」。若平台按添加顺序自动编号，**必须先加 4~9、再加 10~22**，保证编号与代码一致；平台支持手填编号就直接填。
4. **配数值播报**：1~3 号做成变量播报，串口输入类型选 8 字节 double、小端。
5. **生成固件**：平台导出 `.bin`，用 USB-TTL 接模块下载口烧录（具体引脚与工具以模块手册为准）。
6. **接回主板**：模块插回 UART2，确认 TX/RX 交叉、共地。
7. **打开主板开关**：`include/home_safety.h` 里把 `VOICE_DEDICATED_IDX` 改为 `1`（报警 4~8 与应答 10~22 一起启用），服药播报再把 `SU03T_MEDICINE_PROFILE_ENABLED` 改为 `1`。
8. **重新编译烧主板**：见 `device/rk2206_home_safety/README.md` 的构建说明。

## 6. 烧录后怎么验证（不用一条条试）

固件内置了上电自检：

```bash
# 临时打开自检：上电后从 4 号到 22 号逐个播报，每句间隔 2 秒，约 38 秒播完
# 在编译参数里加 -DSU03T_SELF_TEST=1
```

串口日志会同步打印，哪条没声音、播错，一眼能对上号：

```
[voice] self test queued 4..22
[voice] self test index=4
...
[voice] self test index=22
```

验证完**务必把 `SU03T_SELF_TEST` 改回 0**，否则每次开机都会念一遍。若日志打印 `self test skipped (VOICE_DEDICATED_IDX=0)`，说明第 7 步的开关没打开。

人工验收清单：

- [ ] 喊「小颐」有应答，5 秒内能接指令
- [ ] 「小颐开灯 / 关灯 / 自动灯光」→ 灯变化 + 播 10/11/12 号
- [ ] 「小颐救命」→ 蜂鸣与红灯起，播 13 号；「小颐没事了」→ 解除并播 14 号
- [ ] 「小颐静音」「小颐恢复播报」→ 播 15/16 号
- [ ] 「现在温度多少」→ 播真实温度，不是 0
- [ ] 「燃气浓度多少」→ 正常/偏高分别播 21/20 号
- [ ] 制造一次无活动报警 → 播 4 号，不是温度模板
- [ ] 断电重启后以上仍成立

## 7. 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 报警时播「温度 0 度」 | `VOICE_DEDICATED_IDX` 还是 0，报警编号落到了出厂数值词条 | 改 1 并重编主板 |
| 只有 1~3 号有声音 | 4~22 号未在模块配置 | 按第 3、4 节补词条并重烧 |
| 播报顺序错乱、说的是别的句子 | 平台自动编号与代码不一致 | 核对编号，必要时按顺序重建 |
| 温度播成乱码/负数 | 数值帧不是 8 字节 double 小端 | 改模块串口输入类型 |
| 完全无声音 | 波特率不是 115200，或 TX/RX 接反 | 核对接线与 `su03t_init()` |
| 串口日志有发送、模块不响 | 该编号词条为空或未启用 | 用自检模式逐条核对 |
